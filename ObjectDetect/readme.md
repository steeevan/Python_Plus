# 👁️ Python OOP Lesson: Real-Time Object Detection with a Camera

## 🎯 **Objective**

Students will learn how to:

* Access and process live webcam video using Python and OpenCV
* Detect objects (e.g., faces) using pre-trained classifiers
* Apply **Object-Oriented Programming (OOP)** principles to modularize and structure a computer vision project

---

## 🧠 **Concepts Covered**

| Topic                | Description                                                             |
| -------------------- | ----------------------------------------------------------------------- |
| Webcam Video Capture | Using OpenCV to access and stream video from a webcam                   |
| Object Detection     | Using Haar Cascades for detecting faces or other features               |
| OOP Design in Python | Structuring a program into multiple classes and files                   |
| Code Reusability     | Creating helper functions for repeated tasks (e.g., drawing rectangles) |
| Live Feedback        | Visualizing detections in real time on video frames                     |
